  • راه‌اندازی معماری کانتینری با استفاده از Dockerfile و Docker Compose
  • طراحی دیتابیس و مدیریت مایگریشن‌ها
  • ارتباط ایزوله بین کانتینر اپلیکیشن جنگو و دیتابیس
